# DXF Preview для Windows 11

Розширення Провідника Windows для файлів `.dxf`:

- **Мініатюри**: замість іконки в режимах «Великі / Величезні значки» показується креслення.
- **Панель попереднього перегляду** (Alt+P): креслення з масштабуванням і зсувом.

Працює без AutoCAD і без сторонніх бібліотек. Це одна невелика DLL, яка використовує лише GDI+ із Windows.

## Що вміє

| | |
|---|---|
| Примітиви | LINE, CIRCLE, ARC, ELLIPSE, LWPOLYLINE і POLYLINE (з дугами-bulge, 3D, polyface, mesh), SPLINE (NURBS і fit points), SOLID/TRACE, 3DFACE, LEADER, MLINE |
| Блоки | INSERT (масштаб, поворот, дзеркало, масиви, вкладені блоки, атрибути ATTRIB), DIMENSION (розміри), ACAD_TABLE |
| Штриховки | HATCH: суцільна заливка з отворами, шаблонні (ANSI31 тощо, із штрихами), градієнт показується заливкою |
| Текст | TEXT і MTEXT: вирівнювання, поворот, стиснення, багаторядковість. Форматування MTEXT очищується |
| Кирилиця | ANSI_1251 (старі DXF), UTF-8 (AutoCAD 2007+), `\U+XXXX`, `%%c` (Ø), `%%d` (°), `%%p` (±) |
| Шари | Вимкнені й заморожені шари не показуються. Кольори: BYLAYER, BYBLOCK, ACI, True Color |
| Інше | Показується простір моделі (Model). Якщо він порожній, показується аркуш. Поодинокі «загублені» об'єкти далеко від креслення ігноруються під час автомасштабу |

**Не підтримується**: двійковий DXF (рідкісний), типи ліній (усе малюється суцільною лінією), товщини ліній, шрифти SHX (замість них Arial), растрові вставки IMAGE, 3D-тіла (3DSOLID/REGION). На вигляд креслення це майже не впливає.

## Керування в панелі перегляду

| Дія | Як |
|---|---|
| Масштаб | Колесо миші (відносно курсора), `+` / `−` |
| Зсув | Перетягування лівою або середньою кнопкою, стрілки |
| Показати все | Подвійний клік, правий клік, `Home` або `0` |
| Світлий / темний фон | `B` (запам'ятовується й діє також на мініатюри) |

## Збирання

Потрібна безкоштовна **Build Tools for Visual Studio 2022** (або повна Visual Studio) з компонентом «Desktop development with C++».

1. Відкрийте папку проєкту.
2. Запустіть `build.bat`.
3. Отримаєте `build\DxfPreview.dll` і `build\dxfthumb.exe`.

**Без Visual Studio**: залийте папку в репозиторій GitHub. Вбудований workflow (`.github/workflows/build.yml`) сам збере DLL. Готовий архів лежить у вкладці *Actions → останній запуск → Artifacts → DxfPreview*.

Альтернатива через CMake: `cmake -B build -A x64 && cmake --build build --config Release`.

## Встановлення

1. Запустіть `install.bat` і погодьтеся на права адміністратора. DLL копіюється в `C:\Program Files\DxfPreview\` і реєструється через `regsvr32`.
2. У Провіднику ввімкніть «Вигляд → Панель попереднього перегляду» та/або «Великі значки».
3. Якщо замість мініатюр досі видно старі іконки, запустіть `clear-thumbnail-cache.bat`.

Видалення: `uninstall.bat`.

> Якщо мініатюри не з'являються взагалі, перевірте, що в «Параметрах папок → Вигляд» **не** ввімкнено «Завжди відображати значки, а не ескізи».

> Якщо на комп'ютері стоїть програма, яка теж реєструє свої прев'ю для DXF (наприклад, деякі CAD-переглядачі), Windows може віддавати перевагу їй. Тоді переустановіть цей пакет після неї.

## Перевірка без встановлення

`dxfthumb.exe` малює DXF у PNG тим самим кодом, що й розширення, і показує час розбору та малювання:

```
build\dxfthumb.exe креслення.dxf результат.png 1600
build\dxfthumb.exe креслення.dxf результат.png 1600 --light
```

Якщо якийсь файл показується неправильно, цим інструментом зручно відтворити проблему.

## Структура

```
src/dxf_core.*            розбір DXF -> 2D-геометрія (переносний C++17, без залежностей)
src/render_gdiplus.*      малювання через GDI+
src/thumbnail_provider.cpp  IThumbnailProvider (мініатюри)
src/preview_handler.cpp   IPreviewHandler (панель перегляду, зум/зсув)
src/dll_main.cpp          COM-фабрика, реєстрація в реєстрі
tools/dxfthumb.cpp        консольна утиліта DXF -> PNG
tests/                    тестові DXF і генератор (tests/gen.py)
```

Технічні деталі:

- **Реєстрація**: обробники прописуються для `.dxf` та `SystemFileAssociations\.dxf` у HKLM. Прев'ю працює в стандартному `prevhost.exe`, мініатюри в ізольованому `dllhost.exe`, тож збій розширення не обвалить Провідник.
- **Обмеження**: мініатюри будуються для файлів до 300 МБ, прев'ю для файлів до 1 ГБ.
- **Великі креслення**: понад ~25 млн точок геометрія обрізається, і в панелі з'являється примітка.
